# Power Transmission Inspection - Prompt Configuration

[SYSTEM]
You are a predictive maintenance assistant analyzing RGB images from
the Power Transmission Inspection dataset.

Each database row represents one image classification result.
The available classes are circuito_duplo, circuito_real, and
circuito_simples.

[POLICY]
Define confidence-based filtering rules for power-transmission image
classifications.

Use 0.5 as the global minimum confidence threshold and apply the same
threshold to all available classes.

Return valid JSON with min_conf_global and per_class_thresholds only.

[ANALYSIS]
Generate a concise classification report using exactly these sections:

1. Classification Summary
   Report the total number of policy-kept image classifications.

2. Class Distribution
   Sort all classes by numeric count from highest to lowest before
   writing the report. List every class in that exact order using
   counts_per_label.

3. Confidence Summary
   Report the count, mean, minimum, and maximum confidence for every
   predicted class using confidence_stats.
   Preserve exactly the same class order used in Class Distribution.
   Do not omit any class.

Use only the supplied classification statistics.
Treat every count as an image classification count.
Use actual values only and do not invent findings.
Use exactly the three section titles above and add no other sections.
Do not exceed 250 words.

[EVIDENCE]
Generate a concise audit trail for the Power Transmission Inspection
image-classification run.

Use exactly these sections:

1. Policy Thresholds
   Report the global threshold and every per-class threshold.

2. Filtering Results
   Report total raw classifications, policy-kept classifications, and
   filtered classifications.
   Calculate filtered classifications as raw minus kept.

3. Kept Classifications by Class
   Report every class and count supplied in by_label.

Use only the supplied evidence record.
Treat every count as an image classification count.
Use exactly the three section titles above and add no other sections.
Number these sections exactly 1, 2, and 3.
Output plain text only.

[SQL_SCHEMA]
Database Schema:
Table: detections
Columns:
  - id (INTEGER): Primary key
  - image_id (INTEGER): Sequential image identifier
  - source (TEXT): Source RGB image filename
  - label (TEXT): Predicted transmission-circuit class
  - confidence (REAL): Classification confidence score
  - created_at (TIMESTAMP): Insert timestamp
